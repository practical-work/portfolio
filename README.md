Welcome to my personal portfolio website.

This portfolio represents my journey as an aspiring Machine Learning Engineer and showcases my skills, projects, learning path, and technical experience in Artificial Intelligence, Machine Learning, Data Science, and Full Stack Development.

The website is designed with a modern responsive UI, dark/light theme support, animations, and recruiter-friendly sections.
